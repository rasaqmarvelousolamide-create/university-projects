Project 1: Lottery Simulator

Description: A Java console program that lets the user enter six unique numbers between 1 and 50, draws six unique random numbers, counts the matches, saves both sets to a text file, then reads the file back to check the saved data.

Technologies: Java java.util java.io BlueJ

My role: Sole developer for the University of Dundee module ICI10040. I designed the program structure, wrote the code, tested it and documented it in a report.

Challenges and skills gained: Random numbers can repeat, so I wrote a helper method that checks the array before accepting a number. Input validation (range, duplicates, non-numbers) and keeping user and drawn numbers separate in the saved file were the hardest parts. I solved them with labelled lines in the file and repeated testing. I gained experience in arrays, methods, file handling, error handling and debugging.

Example: counting matches in Java (from my Lottery Simulator)

public static int countMatches(int[] arr1, int[] arr2) {
    int matches = 0;
    for (int num1 : arr1) {
        for (int num2 : arr2) {
            if (num1 == num2) {
                matches++;
                break; // count each number once
            }
        }
    }
    return matches;
}
